# Verificação da versão acadêmica

Verificação técnica realizada em 31/10/2026, após a adaptação do projeto. Esta data se refere à revisão do software, não à data dos atendimentos declarados no relatório.

- Build de produção do Angular concluído.
- Dois testes Jasmine existentes passaram no Chrome Headless.
- Consulta de cadernos retornou o código 4820.20.00; busca sem correspondência limpou os resultados anteriores.
- Roteiro marcado e exportado manteve a marcação no arquivo baixado.
- Exercício de receita e lucro apresentou a explicação da alternativa escolhida.
- Tela com 390 pixels de largura sem transbordamento horizontal.
- Nenhum erro JavaScript durante o percurso da interface.
- Os dois serviços Go foram compilados e responderam à verificação de saúde.
- Cadastro e edição de produto foram gravados e recuperados no SQLite; cadastro vazio foi rejeitado.

As capturas usam exemplos fictícios. A tabela NCM é uma cópia local; a consulta não comprova a classificação fiscal de um produto específico. Os módulos fiscais e as alíquotas continuam demonstrativos. O build informa um aviso de tamanho de CSS e um aviso de módulo CommonJS do OCR opcional; ambos permitem a geração do aplicativo.

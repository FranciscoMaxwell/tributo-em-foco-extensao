# Interface do Tributo em Foco

Execute `npm ci` e `npm start` nesta pasta. Abra http://localhost:4200.

A aba Aprender funciona sem os serviços Go. Para Produtos, Notas, Precificação e Contabilidade, inicie os serviços conforme o guia da pasta principal.

Verificação: `npm run build` e `npm test -- --watch=false --browsers=ChromeHeadless`.
